# 前沿技术研究 Web 发布资产库（Assets）

本目录为 **Web 线上运行时发布资产库**。

> **核心原则**：**整包发布，零心智负担！** 
> 本目录内 **100% 都是网页展示和在线阅读必需的轻量化资源**（总计约 14.2 MB），没有任何未使用的重型 PPTX/DOCX 办公母版。部署时直接把整个 `assets/` 目录随网页一起带走即可！
