# 银行金融科技前沿技术研究成果 · 电子研究书
> **Bank FinTech Frontier Technology Research Deliverable · Digital Interactive Book**  
> 一套**纯静态、零依赖、离线可用**的银行业金融科技前沿技术研判与决策支撑平台。

---

## 📌 项目定位与业务背景

本项目旨在为银行管理层、技术委员会、金融科技架构师及业务创新团队提供一套**前瞻性、全景式、强交互**的前沿技术研究成果展示与决策支撑工具。

- **数据基础**：严格遵循《前沿技术储备库分层台账 v1.30》，纳入 **36 项**前沿关键技术；
- **战略方向**：全面覆盖 **人工智能、数据要素、量子科技、网络安全、金融基础设施** 五大领域；
- **研判模型**：采用**“六维评估体系”**（技术成熟度、战略匹配度、价值贡献度、引入可行度、战略紧迫度、生态开放度，1–5 分制）；
- **动态分层**：基于研判结果，将技术动态归入四层梯队：
  - **🚀 布局层（6 项）**：提前布局，资源前置、治理先行（如自主型AI智能体、数据织网、算力网络等）；
  - **🔬 论证层（10 项）**：系统论证，验证业务边界与落地可行性（如事件驱动架构、AI安全平台、零信任等）；
  - **🔍 研究层（10 项）**：深入研究，跟踪核心机理与演进拐点（如合成数据、因果AI、可观测性等）；
  - **👀 观察层（10 项）**：动态观察，关注生态成熟度与外部驱动信号（如量子计算、后量子密码、WebAssembly等）。

## 🌟 核心功能与三大交互视图

系统针对不同的汇报、阅读与研讨场景，深度定制了**三大阅读视图**与**专题材料中心**：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                                核心交互与功能                                │
├─────────────────────┬──────────────────────────┬─────────────────────────────┤
│   📖 书籍模式       │       🌐 网页模式        │        🌳 科技树模式        │
│ (拟真 3D 纵向翻页)  │  (左侧目录 + 右侧长卷)   │    (分层依赖拓扑网络)       │
├─────────────────────┴──────────────────────────┴─────────────────────────────┤
│                          📑 深度专题研究与材料中心                           │
│  [ 一张图概述(SVG) ] [ 六维评估表 ] [ Word深度报告预览 ] [ PPT演示全屏放映 ] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 1. 📖 书籍模式（Book Mode · 拟真 3D 翻书）
* **翻页体验**：纯 CSS 3D 变换打造的跨页翻书动效，支持键盘左右键、边缘点击与导航按钮平滑翻阅；
* **专属竖版流式排版（Vertical Layout）**：
  * **顶部身份区**：技术编号徽章、全称、英文名、所属战略方向与分层标签；
  * **大号六维蜘蛛图（占宽 50% / 1:1 方形比例）**：高亮顶点得分，直观呈现技术成熟度与战略紧迫度等优劣势；
  * **研判结论与处置建议**：紧跟雷达图右侧，提炼专家组定档决策与引入建议；
  * **四大深度剖析板块**：自上而下顺畅流式展开：
    - 💡 **技术定义与机理**
    - 🚀 **颠覆性趋势演进**
    - 🏦 **对银行的价值贡献**
    - ⚠️ **当前局限性与合规风险**

### 2. 🌐 网页模式（Web Mode · 宽屏仪表盘）
* **左侧多级目录**：涵盖扉页、工作方案、情报源评判、储备库、图谱及 36 项技术专题，支持快速定位；
* **智能滚动监听（Scrollspy）**：右侧滚动时，左侧目录条目自动实时高亮；
* **横向宽幅仪表盘（Horizontal Dashboard）**：
  * **左侧量化分析柱（350px）**：大号雷达蜘蛛图 + 六维得分条 + 研判结论卡片；
  * **右侧 2×2 宽幅矩阵**：宽屏舒展平铺定义、趋势、价值与局限性四大卡片。

### 3. 🌳 科技树模式（Tech Tree Mode · 演进依赖）
* **分层时代演进**：梳理技术间的“前提依赖、互补协同与竞争替代”关系；
* **三层架构**：
  - **第 0 层 · 基础底座**（大模型、云原生、密码学、区块链、芯片算力等）；
  - **第 1 层 · 使能技术**（向量检索、零信任、事件驱动等）；
  - **第 2 层 · 系统与业务应用**（AI智能体、业务编排BOAT、决策智能DIP等）；
* **交互画布**：支持鼠标滚轮平滑缩放、拖拽平移、重置视图与节点点击直达。

### 4. 📑 专题研究与材料中心（Modal & Panel）
针对已深化的重点技术（如算力网络、AI安全平台、业务编排BOAT、决策智能DIP等），提供全屏交互弹窗：
* **一张图概述**：超高清矢量 SVG 图解，支持灯箱放大；
* **评估表**：多轮雷达对比、32 字段台账与六维研判依据；
* **Word 报告**：原生内嵌高保真预览，支持全屏与离线下载；
* **PPT 幻灯片**：演示级幻灯片内嵌预览，支持全屏播放与下载。

## 🛠️ 技术特性与架构设计

1. **零外部依赖（Zero-Dependency）**：
   - 纯原生 **HTML5 + CSS3 + Vanilla JavaScript + SVG** 构建；
   - **无需安装 Node.js/Python 即可运行**，无需 React/Vue 构建，无任何外部 CDN 请求；
2. **离线首选（Offline-First）**：
   - 直接双击 `index.html` 或 `start.bat` 本地秒开（采用 `data.js` 架构，彻底规避浏览器 `file://` 跨域拦截问题）；
3. **全局毫秒级搜索**：
   - 支持对技术名称、英文缩写、所属层级、战略方向及简介的实时模糊检索；
4. **双主题配色**：
   - 内置 **深色金融极客（Dark）** 与 **浅色专业报告（Light）** 两套高保真金融级主题，支持一键平滑切换。

## 🚀 快速开始

### 方式一：直接双击运行（推荐）
- 直接双击项目根目录下的 **`start.bat`** 或 **`index.html`**；
- 浏览器即可在零网络、零服务器环境下直接加载并呈现完整内容。

### 方式二：本地 HTTP 服务运行
如果需要在局域网内共享或通过本地服务器打开，可在根目录下执行任意一条命令：
```bash
# 使用 Python 启动
python -m http.server 8080

# 或使用 Node.js 启动
npx serve .
```
浏览器访问 `http://localhost:8080` 即可。

## 🔄 数据维护与二次开发指南

### 1. 新增或修改前沿技术数据
1. 打开 `data.js` 文件；
2. 在 `ITEMS` 数组中添加或修改对应技术对象（包含 `name`, `category`, `tier`, `maturity`, `strategicFit`, `value`, `feasibility`, `urgency`, `openness`, `conclusion`, `definition`, `trend`, `bankValue`, `limitation` 等字段）；
3. 关系网络将在加载时通过 `buildGraph()` 自动联动更新。

### 2. 接入新增技术的专题报告素材
1. 将编写完成的 Word 报告与 PPT 放置于 `assets/docs/<技术ID>/` 目录下；
2. 转换为 PDF 后放置于 `assets/preview/<技术ID>/` 供内嵌预览；
3. 将“一张图概述”SVG 放置于 `assets/images/`；
4. 在 `data.js` 中补齐对应技术对象的 `reportDocx`, `reportPdf`, `slidesPptx`, `slidesPdf`, `image` 路径。

### 3. 一键同步生成单文件版
当修改了 `index.html`、`data.js` 或 `js/app.js` 后，只需在根目录运行打包脚本，即可自动同步更新 `index-standalone.html`：
```bash
node scripts/pack.js
```
