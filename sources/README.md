# 前沿技术研究源文档库（Sources）管理规范

本目录为**工作母版与源文件专区**，专门存放日常办公编辑、留档研究的母版文件。

> **核心原则**：本目录所有文件纯属本地研发与内容沉淀，**在打包或部署 Web 网页时完全不需要携带本目录**！

---
