1. **审查员脱网演示版**：[`前沿技术研究电子书-专利演示版.html`](../前沿技术研究电子书-专利演示版.html)
   - 纯单文件（5.5 MB），已在内存级完全脱敏并剥离内部涉密原件，无外部网络依赖，双击即可在任意电脑上流畅演示 3D 翻书、六维雷达、自适应双向对齐、六大图谱与术语超链全流程。
2. **自动化脱敏重构工具**：[`scripts/pack-patent.js`](../scripts/pack-patent.js)
   - 专用的专利脱敏打包脚本，可随时一键从主工程重新构建轻量级专利演示版本。
3. **高保真架构图母版**：[`前沿技术研究成果集-浦发银行可编辑演示文稿(已更新).pptx`](../前沿技术研究成果集-浦发银行可编辑演示文稿(已更新).pptx)

## 📋 提交申报与代理机构对接建议

1. **申报组合打包（Patent Portfolio）**：
   - 建议采用 **“3 项发明专利 + 6 项 GUI 外观专利”** 一起申报的组合策略，发明专利构筑底层方法与算法壁垒，外观专利以极快周期（3–6个月）快速下证并保护全套界面视觉；
2. **材料交接**：
   - 将本 `patents/` 文件夹整体打包提供给行内知识产权（IPR）专员或合作的知识产权代理事务所即可，各交底书中已包含完整的技术背景、算法公式、附图方案与预拟权利要求书；
3. **图纸制作**：
   - 代理人制作图纸时，只需打开 [`前沿技术研究电子书-专利演示版.html`](../前沿技术研究电子书-专利演示版.html)，在浏览器中将视口设置为 $1920 \times 1080$，按照汇编文档中的说明依次截图即可获得高质量申报图纸。
